Letra 0.5.2 deja la ventana Acerca de solo con lo esencial y limpia el código que ya no se usaba.
*Letra 0.5.2 leaves the About window with only the essentials and removes code that was no longer used.*

## Español

### Correcciones
- **Acerca de**, sin listas de colaboradores ni de modelos: la ventana es la página común de Nodalia (icono, versión, enlaces, licencias y el aviso de autoría original).
- Se retira del programa el código y los datos de esas listas, que ya no se mostraban.

## English

### Fixes
- **About** has no contributor or model lists: the window is the shared Nodalia page (icon, version, links, licences and the original authorship notice).
- The code and data behind those lists, no longer shown, are removed from the program.
